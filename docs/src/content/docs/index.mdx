:::note[Phase 1 MVP released]
t9s implements the full read-only Phase 1 MVP: nodes, services and logs, events, etcd, processes, disks, network, a generic resource browser, explainable health rules, optional Kubernetes correlation, and the k9s launcher. [v0.1.0](https://github.com/m11s-io/t9s/releases/tag/v0.1.0) ships cross-platform binaries and checksums; signed artifacts are not yet included.
:::
