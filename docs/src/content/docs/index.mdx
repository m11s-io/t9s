`t9s` brings Talos nodes, services, logs, events, storage, and networking into
one terminal UI. Move from a cluster overview to the resource you need, with
health findings that show the observations behind them.

<CardGrid>
  <Card title="Explore your cluster" icon="seti:config">
    Browse resources, open details, and follow logs. Filter the view to find
    what matters, or switch contexts to work with another cluster.
  </Card>
  <Card title="Understand the problem" icon="magnifier">
    See which resources need attention, inspect the evidence, and open
    node diagnostics to investigate further.
  </Card>
  <Card title="Read only by default" icon="lock">
    Start by looking around. Maintenance actions, configuration applies, and
    upgrades are opt-in and require confirmation. Read [Security](/security/)
    before enabling writes.
  </Card>
</CardGrid>

## Start exploring

[Install t9s](/getting-started/installation/) with Homebrew or download a
[release binary](https://github.com/m11s-io/t9s/releases), then run:

```bash
t9s
```

Use your existing [Talos configuration](/getting-started/talos-configuration/).
Press `?` for help, `/` to filter, or `:` to open the
[command palette](/reference/commands/).

Already working in k9s? Use the [k9s integration](/guides/k9s-integration/) to
open a selected node in t9s.

For compatibility details and live validation, see the
[contributor guide](/contributing/#compatibility-and-manual-validation).
