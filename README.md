# t9s

`t9s` is a standalone, resource-first terminal UI for exploring Talos Linux clusters.

> Explore a Talos cluster quickly, see what is healthy or unhealthy, and drill from any resource into the evidence.

The project currently contains the node and service explorer foundation, not the full MVP. The supported Talos version is **v1.13.3**.

Documentation: <https://t9s.m11s.io>
